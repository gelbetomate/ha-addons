# Home Assistant Add-on: Example add-on

## How to use

This add-on is a simple example. When started it will print the configured
message to the log.

## Configuration

**Note**: _Remember to restart the add-on when the configuration is changed._

Example add-on configuration:

```yaml
message: Hello world!
```

### Option: `message`

The message that will be printed to the add-on log on startup.
